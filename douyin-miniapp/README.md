# 抖音小程序版 2048

这是原生抖音小程序工程，不依赖服务器、登录或云开发。现有桌面版和普通浏览器版仍保留在项目根目录与 `web/` 中。

## 导入开发者工具

1. 打开抖音开发者工具。
2. 选择“导入项目”，选择本目录 `douyin-miniapp`。
3. 在 `project.config.json` 中将 `ttxxxxxxxxxxxxxxxx` 替换为你的抖音小程序 AppID；没有 AppID 时可先作为本地工程检查代码。
4. 选择真机预览或开发者工具预览。

## 功能

- 4×4 标准 2048 玩法，支持触摸滑动和方向按钮。
- 开发者工具或外接键盘可使用方向键、WASD、Z 撤销、R 重开。
- 进度、撤销历史、随机数状态和音效开关使用 `tt` 本地存储。
- 首次达到 2048 显示胜利提示，关闭后继续挑战。
- 无法移动时显示游戏结束提示，可撤销或重新开始。
- 只有合并方块时播放 `assets/win_A.wav`。

## 发布前检查

- 替换真实 AppID。
- 在开发者工具和真机检查触摸滑动、音效和本地恢复。
- 按抖音平台要求配置小程序名称、头像、类目和隐私说明。
- 通过平台审核后再提交发布。

## 目录

- `app.js`、`app.json`、`app.ttss`：小程序入口和全局配置。
- `pages/index/`：2048 页面、交互和移动端样式。
- `utils/game.js`：不依赖界面的规则模块。
- `assets/win_A.wav`：用户选定的合并音效。
